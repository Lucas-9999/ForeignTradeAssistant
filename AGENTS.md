# Portfolio development instructions

This repository is a recruiting showcase using synthetic data.

- Preserve existing copyright and license notices. Do not invent authorship or a new license.
- Keep the demo local, read-only and independent of credentials, browser sessions and production databases.
- Do not enable collection, SMTP/IMAP, WhatsApp, or scheduler jobs during review or tests.
- Preserve the core sending guard, one-time authorization, quotas and explicit schema gate.
- Never commit .env values, runtime databases, browser profiles, logs, backups or recipient lists.
- Test changes with temporary databases and mocked external services. Describe runtime AI capability accurately: this snapshot has no LLM inference pipeline.
